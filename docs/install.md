Install "factory" ESPHome firmware to your Seeed Studio reTerminal E1004 device.

Uses [ESP Web Tools](https://esphome.github.io/esp-web-tools/) which uses [Web Serial](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API) to download the firmware to the device. ESP Web Tools is compatible with Mozilla Firefox, Google Chrome, Microsoft Edge and Google Chrome on Android.
